# Brand assets: a0-plugin-argus

PROPOSAL: the owner signs off logos. Nothing here is final until then.

Part of the Patchbay family (see `DESIGN.md`). Hand-written SVG, generated by `family-build.py`; no raster sources, no stock icons, no generated imagery.

## Construction

- 64 x 64 grid.
- Frame: rounded square, outer edge 4..60, outer corner radius 8, 6-unit stroke, no fill.
- Corner pin: 14 x 14 filled block in the signal colour at the bottom-right of the frame, outer radius 8 so it continues the frame outline.
- Glyph box: 28 x 28 at 16..44, strokes 4 units, butt caps, mitre joins, straight segments only.

## This repo's glyph

A diamond (an eye, for Argus the many-eyed watcher) with a vertical slit pupil. Straight segments only, so the eye is a rhombus, which also reads as a diff lozenge. The slit keeps the inside open at 16 px (frame 1.5 px, stroke 1 px).

## Files

`logo.svg`, `logo-dark.svg`, `wordmark.svg`, `wordmark-dark.svg`, `social-card.svg`, `social-card-dark.svg`, and a PNG preview of each. Wordmark text is outlined with inkscape, so no font is needed to display it.

## Rebuild

```bash
python3 assets/brand/family-build.py argus assets/brand
for f in assets/brand/*.svg; do resvg "$f" "${f%.svg}.png"; done
oxipng -o 4 assets/brand/*.png
```

The build needs `inkscape` (text outlining), `resvg` and `oxipng`, and the JetBrains Mono Nerd Font installed.
